# Lada English Quest — Android/PWA

Версия подготовлена под Android как PWA (Progressive Web App).

## Что изменено

- mobile-first интерфейс;
- нижняя навигация, удобная для телефона;
- PWA manifest;
- режим `standalone` — после установки приложение открывается без обычного интерфейса браузера;
- кнопка установки, когда Chrome предлагает PWA;
- service worker для кеширования оболочки;
- микрофон и распознавание речи;
- AI-репетитор через серверный `/api/tutor`;
- API-ключ остаётся на сервере;
- родительская панель адаптирована под маленький экран.

## Важное ограничение

PWA не может сама по себе безопасно содержать секретный AI API-ключ. Поэтому сервер из этого проекта должен быть размещён в интернете. Телефон будет обращаться к серверу по HTTPS.

## Как пользоваться на Android

1. Разместить проект на сервере с Node.js 18+.
2. Настроить `OPENAI_API_KEY` на сервере.
3. Включить HTTPS.
4. Открыть адрес сайта в Google Chrome на Android.
5. Выбрать `Установить приложение` / `Добавить на главный экран`.
6. Разрешить микрофон, когда Chrome попросит доступ.

Для распознавания речи нужен интернет и актуальный браузер. Поведение Web Speech API зависит от версии Chrome, устройства и региона.

## Локальный запуск

На компьютере:

```bash
npm start
```

Затем можно открыть адрес компьютера с телефона, если оба устройства находятся в одной сети, но для микрофона браузеры могут требовать HTTPS. Для реального использования лучше деплой по HTTPS.

## AI

Создайте `.env`:

```text
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-5.6-mini
PORT=3000
```

Не публикуйте `.env` и не вставляйте API-ключ в `index.html`.

## Следующий production-шаг

Для реального использования ребёнком нужно добавить родительскую авторизацию, защищённую БД, HTTPS, rate limiting, аудит данных, резервные копии, политики хранения детских данных и полноценный фонемный анализ произношения.
